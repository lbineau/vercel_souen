# Iacomo Malatesta
**Lieu(x):** [[05 - Lieux/Altabianca\|Altabianca]]
- Parfumeur royal, disparu après affaire avec royaume d'Aria
- Créait le "songe d'Osmanlie", parfum censé guérir la mélancolie
- Amoureux d'Acelia (prostituée Osmanlienne)
- Devenu [[04 - Lore/Créatures/Tulpa\|Tulpa]] (vu dans le laboratoire secret sous le manoir Malatesta)
